# Repository API R&D

This repository is a sandbox project for exploring GitHub REST APIs.

## Objective

The purpose of this repository is to perform a proof of concept for repository access using the GitHub REST API.

The R&D focuses on:

* Retrieving repository commits
* Retrieving pull requests
* Understanding API response structures
* Working with API authentication
* Calculating basic repository statistics
* Generating a summary report

## Technology

* Node.js
* GitHub REST API

This is a test repository and does not contain production data.

## Planned POC

The proof of concept will:

1. Authenticate with the GitHub REST API.
2. Retrieve commits from the repository.
3. Retrieve pull requests from the repository.
4. Filter activity from the last 30 days.
5. Calculate basic repository statistics.
6. Generate a JSON summary report.
